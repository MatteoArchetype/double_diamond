# Product direction: a research tool based on Double Diamond

The user confirmed that Double Diamond must guide the tool's design decisions.
Its purpose is to help turn a broad question into a well-supported decision:

Discover different perspectives and evidence; Define the problem that matters;
Develop competing explanations or options and ways to test them; Deliver a research
judgment supported by evaluations, with uncertainty and the next decision made clear.
Return to earlier work when new evidence changes the understanding.

The tool should make that research understandable and inspectable. Sources, claims,
hypotheses, uncertainty, synthetic examples and human decisions need distinct labels.
Earlier findings and the reasons for changing them should remain available. A report
is a communication artifact; it is not by itself evidence that an explanation or solution
has been validated. Human review controls consequential changes and external actions.

Storage, recovery and audit features support that research process. They are not a
substitute for a usable research experience. Current limits include host-provided
identity/source verification and real empirical research, a first local interface
awaiting actual user acceptance, and no external execution or publication. Synthetic demonstrations validate
engineering behavior, not real-world findings or actual human acceptance.
