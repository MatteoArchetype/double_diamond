# Cycle 173 · Compare planned tests with recorded methods in Deliver

In a Deliver draft, expand **See what was planned in Develop** in an evaluation row. The app shows the saved proposed test and assumptions for the alternative selected in that row. Changing alternatives updates that reference. Enter the method actually used separately.

**Review evaluation draft coverage** shows which alternatives have an evaluation row with a method entered. It updates as rows and methods change. Counts describe draft entries and do not establish that a test was completed. The assessment, recommendation and phase boundaries are unchanged.
