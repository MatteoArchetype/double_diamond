# Cycle 169 · Assess evidence from a saved interpretation

Under **Interpretations**, each saved interpretation lists linked passages and their assessment status. Choose **Assess passage from…** to open **Evidence fit** with the exact interpretation and passage selected.

Unsaved ratings, limits and reasoning are kept separately for each pair within the current case revision and browser session. Switching to a different pair starts with Unknown ratings unless that pair already has a draft. Existing assessments stay visible, including those marked stale. The researcher still explicitly saves each advisory assessment.
