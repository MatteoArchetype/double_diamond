# Cycle 158 · Word document autofill

From **Sources**, choose a .docx file in **Fill in details from a Word document**, then select **Read document details**. The app displays the title, author, publication date and original web link if those fields are embedded in the file properties. Select **Use these details** to copy them into an empty review form.

The preview is local and temporary. It does not retain the original file or infer details from the document body. The current review workflow still requires a source web link, exact passage, context and explicit approval. A publication date can now be retained when you approve a source. PDF import, file-only evidence and retrieval-augmented generation are outside this release.
