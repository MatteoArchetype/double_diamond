# Keep disagreement visible through the Double Diamond

In **Interpretations**, record at least two advisory interpretations. Choose **Keep a
disagreement visible**, explicitly select two different interpretations, describe where
they disagree and why the tension should be retained. **Save unresolved disagreement**
creates an advisory record with status unresolved. No option is selected by default.

The tool does not establish that a logical or empirical contradiction actually exists.
The disagreement may concern scope, assumptions, missing perspectives or competing
explanations. Recording it neither chooses a winner nor weakens human review. It creates
no evidence, changes no source/synthetic flag and does not change either claim's status.
Interpretations without evidence can still be compared; absence of evidence stays visible.

**Recorded disagreements** shows the current versions of linked interpretations and
source passages. It does not claim these are the exact versions at original disagreement
creation. A report snapshot retains its own versions: **Disagreements at report creation**
uses only that report's embedded interpretations and source records. Historical report
labels stay visible, and later live edits are never substituted into its comparison.
Expand retained source passages to inspect location, publisher and synthetic distinction.

A saved disagreement makes an earlier report stale. It does not rewrite prior phase
findings, automatically stale every phase, reframe Define or progress/reopen research.
Review the tension when framing Define, comparing alternatives in Develop and assessing
criteria in Deliver. An intended return or changed frame still uses the existing exact
human gates. A report is not publication approval or independent validation.

The browser currently creates unresolved disagreements only. Editing, resolution and
deletion remain library/host operations. Imported saved resolution statuses/bases are
shown as records, not independently verified conclusions. Repeated deliberate entries
create separate records; no semantic deduplication of a pair or issue is claimed. Invalid,
unauthorized, interrupted or stale requests leave saved research unchanged. Check saved
state before retrying an uncertain response. Unsaved forms do not survive reload/closure.

Checkpoints retain disagreements and history; restoration grants no fresh approval. The
interface remains local/single operator. No automatic experiment, external action, source
retrieval, source/reviewer authentication or final human acceptance is performed here.
