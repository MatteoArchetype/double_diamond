# Keep open research questions visible

In **Interpretations**, choose **Record an open research question**. Enter what remains
unknown and why it matters. Select only the existing interpretations it affects, if any.
**Save open uncertainty** saves the question with status open and those explicit links in
one transaction. Empty selections are allowed: Discover may identify a gap before any
interpretation exists. No link or answer is inferred.

New interpretations can select recorded uncertainties as well as evidence. These choices
are independent: a question is not evidence, and linking one does not confirm a claim.
Interpretations stay advisory. Existing source passages and synthetic labels are retained.
The interface shows each interpretation's linked questions and each question's linked
interpretations. Historical resolved/closed statuses from imported checkpoints are displayed
as saved records, not independently validated answers.

In **Define**, choose the uncertainties relevant to the problem frame explicitly. Creating
an uncertainty or linking it to an interpretation does not automatically select it for
Define. Revising an already saved frame still needs the existing exact review gate; past
visits are never rewritten. Later analysis may stale reports or phase bases. Inspect the
original finding and request reviewed return before relying on changed research.

Only creation of open questions is exposed here. Existing questions cannot be overwritten,
resolved, closed or deleted through this form. Editing existing links/questions and broader
analysis remain library/host workflows. Up to 99 existing interpretations may be linked
when creating one question, within the existing 100-command atomic analysis bound.

An invalid, stale, unauthorized or interrupted save commits neither the question nor partial
links. No automatic retry or request deduplication is promised through the browser. Check
saved research before repeating an uncertain response. Unsaved forms survive section
navigation within a page/revision, not reload or closing the browser. Save before refresh.
Checkpoints retain saved questions, links and audit history. They do not grant new approvals.

This is a local single-operator tool. Research validity, independent source acquisition,
source/reviewer authenticity, final acceptance and publication remain human responsibilities.
