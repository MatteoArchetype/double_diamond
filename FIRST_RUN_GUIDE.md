# Try the tool before starting real research

Launch the local interface using Start Research.command and open its private local link.
You can explore the tool without supplying a research question or using a terminal option.

## Start with the clearly labelled learning example

In an empty workspace, choose **Create synthetic learning example**. If cases already
exist, choose **New research case** to find the same option. It creates a separate saved
case with invented evidence, example phase records and simulated historical approvals.
It is not real research, source verification, user acceptance or publication permission.
Each deliberate click creates another case; existing research is unchanged.

The case is visibly labelled synthetic. Its saved draft explains uncertainty and missing
evidence. Use the phase buttons to inspect the Double Diamond records and their original
passages. History shows earlier frames. Reports shows current drafts first (newest first) and retains earlier drafts clearly
labelled historical/stale; Next research
contains unexecuted proposals. The original example has a bounded visit budget and may
not have enough remaining visits for another complete pass. Do not infer permission or
validation from its simulated approvals.

If a response is uncertain, inspect Your research before clicking again. Creation is not
retried automatically. This first interface does not deduplicate example creation across
requests. Code ZIPs do not contain user workspaces or replace research checkpoints.

## Follow the current state

Research now includes **Where you are**, with a proposed next navigation step. It can
point you to source review, advisory interpretations, work in the current phase, saved
research reviews, approved changes awaiting application, or saved report options.

The panel is derived from the same verified saved case/revision shown in the interface.
It does not save a finding, advance a phase, approve a proposal, apply an approval,
retrieve sources, contact participants, run experiments or authorize publication.
Existing mutation permissions, exact-content gates and stale-revision checks still apply.

Expand Saved progress and remaining visits to see which current findings are saved,
missing or need review. These are record statuses, not a methodology score or a finding
that evidence is sufficient. A changed interpretation can mark findings for review.
The final permitted visit can still be recorded; guidance never expands the visit budget.

## When you are ready to start your own case

Create an empty research case with a question, provisional boundaries and visit budget.
Discover first asks for explicitly reviewed evidence, then perspectives and gaps. Define
uses advisory interpretations to frame a problem and criteria; Develop compares competing
alternatives; Deliver records actual evaluations and criterion assessments. Review phase
changes separately, and keep failed or unknown criteria explicit.

The guide helps you find the existing controls. It does not validate sources, methods,
clinical decisions, causal explanations or forecasts. Real-source/user acceptance remains
separate from all synthetic examples and software tests.
