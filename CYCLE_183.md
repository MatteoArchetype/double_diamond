# Cycle 183 · Reduce friction in source review and phase changes

The standard source review form offers **Open original source in a new tab** for a valid web link. When the publisher matches exactly one existing source group for the same synthetic status, the form offers that group for explicit reuse. It does not infer independence or change source approval.

After an approved phase transition is applied successfully, the app opens Research for the resulting phase and moves keyboard focus to its work heading. Approving and applying remain separate. Material frame revisions retain their existing review workflow.
