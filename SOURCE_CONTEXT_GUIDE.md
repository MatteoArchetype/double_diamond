# Inspect the source context saved at intake

Open Sources and choose Inspect saved context for a retained passage. The read-only
panel shows its exact passage and location, synthetic/source-record label, retained
source text and snapshot location, and recorded intake reviewer, decision and reason.
This reopens saved intake records; it does not fetch the current website or approve it again.

If an older intake kept a review but no snapshot, the missing source text is stated
explicitly. Adopted historical evidence without an original intake archive shows that
neither source context nor review is available. The extracted passage alone is never
substituted for missing surrounding text. Different passages' source text is not merged.

The case revision is checked and records are read from one verified, pinned database
snapshot. A stale request is refused. Refreshing or changing cases closes the old panel;
ordinary same-case section navigation retains it. Closing the panel does not change research.

Internal integrity checks detect inconsistent retained records. They do not establish
independent acquisition, source truth, reviewer identity or final human acceptance.
Synthetic material remains labelled. Inspection grants no permission, moves no phase,
changes no interpretation, and approves no framing, publication or external action.

Limits: source text must have been retained at intake. Original pages are not retrieved,
images/PDF layout are not reconstructed, and missing historical text is not recovered.
The local single-operator and browser draft limitations remain. Real research and MVP-08
acceptance remain deferred. All new verification examples use invented material.
