
# Cycle 97 — Discriminating Evidence Selection

The orchestrator should choose evidence that can distinguish between live
explanations, especially when a contradiction or unresolved hypothesis
exists.

Selection considers:
- expected discrimination;
- relevance to the live question;
- independence gain;
- transferability gain;
- retrieval cost.

This is deliberately a prioritisation rule, not a truth score.

Evidence that merely confirms one existing explanation without distinguishing
alternatives is not considered discriminating evidence.
