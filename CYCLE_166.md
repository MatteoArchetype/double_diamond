# Cycle 166 · Find reviewed evidence

In **Sources → Find reviewed evidence**, search for keywords in approved passages. Results show the passage verbatim, its location and a way to inspect retained context. The list ranks passages by the number of distinct matching words, then by exact phrase, and shows up to ten results.

The search runs locally over the current case's loaded evidence. Synthetic practice evidence is excluded by default and labeled when included. Uploaded documents and shortlist entries become searchable here only after a passage is approved. This release retrieves passages and does not generate answers.
