# Cycle 160 · Case document library

In **Sources → Fill in details from a Word document**, choose a .docx file, tick **Keep a local copy in this case**, and select **Read document details**. Reopen it from **Saved Word documents** to search its main-body passages later. Leaving the box unchecked opens a temporary preview.

A case can store 20 Word documents, up to 8 MiB each. Identical bytes are deduplicated within a case and checked against their digest on reopening. Files are local, excluded from case checkpoint downloads, and separate from reviewed evidence. Evidence intake still requires checking context, adding a web link, and explicitly approving the source. Cross-document search, generated answers, and document removal through the interface are outside this release.
