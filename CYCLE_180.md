# Cycle 180 · Save an unfinished Define frame

In an open Define visit, choose **Save draft for later** beneath the frame form. **Open saved draft** restores the problem, success criteria, selected interpretations, selected uncertainties and reason. The evidence context updates to reflect restored selections.

The draft stays on this computer and belongs to the specific open Define visit. It is excluded from case backups. Recording a frame and reviewing changes still use their existing explicit controls.
