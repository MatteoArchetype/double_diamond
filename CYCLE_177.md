# Cycle 177 · Start with a question and find the first source

Creating a case now requires only a research question. **Advanced options** keeps the case name, research boundaries, and existing visit and alternative defaults available. With no custom settings, the question names the case and it begins with an exploratory scope.

Sources is organized around **Find a source**, **Review a passage**, and **Approved evidence**. Each step has a jump control. The review form asks for surrounding text in plain language and retains explicit source approval. Keyboard focus follows opening the new case form, creating a case, opening Sources and navigating research sections.

This cycle does not add persistence for unsaved form drafts.
