# Cycle 163 · Inspect the context around a search result

In **Sources → Saved Word documents**, run a search and open **See surrounding paragraphs** on a result. The app checks the saved file's integrity and shows the matching paragraph with up to two numbered main-body positions before and after it. Gaps in numbering can occur where paragraphs are blank or unavailable.

The context panel is read-only. It does not fill the evidence form or approve a source. The original file remains case-local, and the current Word preview covers supported main-body text.
