# Cycle 162 · Ranked keyword search

In **Sources → Saved Word documents**, choose **Keywords ranked by match** to find paragraphs containing any of the entered words. Paragraphs with more distinct query words appear first, then paragraphs containing the exact phrase, then the original reading order. Each result lists the matched words. **Exact phrase** remains the default.

Search reads supported main-body paragraphs from Word documents saved in the current case. It runs locally and shows up to ten results. Select **Use passage and details** to draft a review with the original filename and paragraph number. Evidence requires explicit approval. This release uses word matching and does not generate answers.
