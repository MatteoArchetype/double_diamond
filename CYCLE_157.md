# Cycle 157 · Bring your own source leads

Open **Sources → Source shortlist → Add a source you found elsewhere**. Enter a title and web link, with the publisher or author if known. Reports, datasets and articles can sit beside Crossref search results in the same case shortlist.

Manual leads use HTTP or HTTPS links without embedded credentials. The app saves the link locally and does not fetch the source. A lead can fill the review form, where an exact passage, source context and explicit approval are still required. Case checkpoint downloads exclude the shortlist.
