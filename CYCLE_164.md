# Cycle 164 · Cite a saved Word document directly

Search in **Sources → Saved Word documents**. Open **See surrounding paragraphs** on a result and then **Review as evidence from this file**. Check the paragraph against the original document, enter its source details and your reason, mark practice material as synthetic, and explicitly approve the passage.

The server checks the saved file's fingerprint and re-reads the selected paragraph before ingesting it. It saves the matching paragraph and nearby text with the original filename, paragraph number and SHA-256 reference. No web link is required. Ordinary web-source review uses its existing form.

A case checkpoint retains the approved evidence, reference and text context. The original Word file remains in the local document library and is outside checkpoint downloads. Word preview supports main-body paragraphs. This release does not generate answers or verify external authorship.
