# Cycle 165 · Reopen the original Word file

Under **Sources**, choose **Inspect saved context** on approved evidence from a Word file, then **Download original Word file**. The same option is available when opening a saved Word document from the case library. Open the downloaded copy in Word to inspect formatting, tables or other content outside the text preview.

Downloads use the original stored bytes, validate the file fingerprint and require access to the current local case. The browser uses the saved filename. If the original is unavailable, the app reports it and the approved text remains available in the evidence record. Case checkpoints still exclude original Word files.
