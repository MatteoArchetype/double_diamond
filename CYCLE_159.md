# Cycle 159 · Search inside a Word document

In **Sources → Fill in details from a Word document**, choose a .docx file and select **Read document details**. Use **Search this document** to find an exact word or phrase, ignoring capitalization. Results show up to ten matching paragraphs in document order. **Use passage and details** fills an empty review form with the paragraph, filename and paragraph number, plus available source details.

Preview searches up to 2,000 top-level main-body paragraphs in supported Word XML. Tables, images, headers and footnotes are outside the preview. An oversized or unsupported body leaves the metadata preview available. Paragraph numbers refer to this preview and are not Word page numbers.

The original file is discarded after preview. Before approving evidence, check the passage against the original and supply the required web link and independently checked context. This feature searches a single preview using literal text matching.
