# Cycle 167 · Carry reviewed passages into an interpretation

In **Sources → Find reviewed evidence**, search for keywords and check the passages you want to consider. Choose **Use selected passages in an interpretation**. The app opens the working interpretation form with those evidence links selected. If there is an existing unsaved interpretation draft for the current case revision, its wording and links are preserved and the selected passages are added.

Search result selections reset when a search is rerun. Synthetic practice evidence remains opt-in and labeled. The app leaves the interpretation wording to the researcher and saves only after **Save advisory interpretation**.
