# Revise a working interpretation while retaining its earlier version

In **Interpretations**, choose **Prepare revision of …** for an eligible advisory draft.
The form starts with its current wording and explicitly selected evidence/uncertainty links.
Review the current saved interpretation, fixed type and fixed status. Change the wording
or links, give a fresh reason and choose **Save advisory revision**. Each explicit save is
an advisory version record, including a deliberate save with unchanged wording.

The browser cannot change claim type, confidence, status or disposition, accept/retain/
promote a claim, edit sources, resolve a question or approve research. The server permits
only records whose analysis status is advisory and whose status/disposition belong to its
conservative draft/unresolved/unknown/hypothesis allowlists. Records with retained, qualified,
narrowed, withdrawn/retracted or promoted disposition use the existing host decision workflow.
No edit button is proof of independent operator identity; server authorization/revisions apply.

Evidence and uncertainty choices replace the explicit link lists. Unchecking a link is a
choice to omit it from this version, not deletion of the source/question. Empty links remain
empty and cannot invent support; unresolved questions remain open. Original synthetic/source
labels and snapshots remain unchanged. Prior claim versions retain their original links.

**Previous recorded versions** shows earlier wording, reason for the subsequent change,
recorded type/status, evidence passages and uncertainty-link count. It includes advisory
link updates as well as wording changes. Full uncertainty references remain in history/audit;
current question text is not substituted as an earlier question version. Original saved
phase visits and reports retain their exact context. The current disagreement view can show
changed claims; report comparisons keep report-time versions.

The edit can stale evidence-fit assessments, phase bases and reports. Inspect those warnings
and request a reviewed return where needed. An advisory claim revision does not itself revise
Define, consume a human gate or reopen/progress the Double Diamond. Save a new assessment only
after reviewing changed research; old ratings are not silently applied to the new claim.

There is one unsaved interpretation revision per page. Preparing another replaces it.
Section navigation preserves that draft independently of new-claim and other forms. Close
unsaved revision cancels the local draft, not any completed transaction. A changed case
revision is refused; retained unsaved wording is shown for reference. Review current saved
research and prepare a fresh draft deliberately. No automatic merge/retry or cross-version
reapplication is offered. Unsaved drafts do not survive reload or closure.

Saved revisions/history survive restart and checkpoint restore. Neither a checkpoint nor
this advisory edit grants fresh approval. The tool remains local/single operator; actual
research, independent authentication, consequential decisions and final acceptance remain
separate human/host responsibilities.
